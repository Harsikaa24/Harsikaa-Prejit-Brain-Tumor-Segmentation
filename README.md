# Brain Tumor Segmentation

This project aims to automate the segmentation of brain tumors from MRI scans using Python, OpenCV, and deep learning techniques. Manual segmentation by radiologists is time-consuming and prone to errors. To address this, the system uses advanced image processing and a U-Net-based model to accurately identify tumor regions.

A user-friendly Streamlit web app allows users to upload MRI images and view the segmentation results. The solution supports applications in diagnosis, treatment planning, telemedicine, and medical research. It is designed to improve accuracy, save time, and enhance patient care through fast, consistent, and reliable tumor detection.
